# Umbra
Umbra is a vision system that was made by a programmer on FRC team 9015, Questionable Engineering. Umbra is a system that was made because we wanted to make a new vision system that could serve our team better than Photon Vision. Currently, it is still very much a work in progress that is not fully functional or fully tested. Right now, if you want to look at it, the code is public, and there is a release made with an alpha version and an image. Currently, we are trying to work on increasing the rate at which it actually updates and trying to make sure the pose is more accurate. Our goal is to have Umbra working and running by the 2027 main season and hopefully for some of the 2026 offseason. If anyone does look at this code or even goes as far as to try it themselves, then please do get in touch and tell us about what you thought. We know there are a lot of issues and kinks that we are trying to work out, but we hope to learn as much as we can and to make this a functioning project. We plan to add some guides for how to actually run the current version on a device soon.
